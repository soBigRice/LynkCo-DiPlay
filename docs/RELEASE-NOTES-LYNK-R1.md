# LynkCo CarPlay R1 · 2026-10-09

首个公开领克 Release 安装包，基于 DiPlay 0.2.12 及本仓库 `d02434b` 的领克适配。
版本 `0.2.12-lynk-osn2-r1`，versionCode 43，包名 `com.shihab.diplay.lynk`，最低 Android 9。

## 本版内容

- 关闭 APK 调试；保留现有领克包名、签名、桌面/CarPlay 图标和平台资源配置。
  test25 及此前同签名领克测试包可以覆盖升级，无需卸载；安装前备份重要设置。
- 包含已有有线 USB 恢复、音频焦点/资源生命周期适配、标准媒体控制、只读环境检测
  和诊断导出；保留 test25 的可选 Dock 空间开关与 Android 9 手动热点权限修正。
- 通过 GitHub Release 分发 APK 与 SHA-256 校验文件；官网和应用更新共享同一份版本元数据。
  公共源码与 CI 不带认证素材或 Android 签名私钥，完整安装包由本地明确输入构建。

## 已知边界

目标车型为 2023 款领克 03 / OS N 2.0 / Android 9。用户曾确认 test17 有线可用、
流畅度尚可；本次 Release 打包不代表新增实车验收。无线目前不能正常使用，仍在调试；
方向盘/原生音乐卡片、Dock 实际效果和其他车型、固件、iOS 版本需独立验证。

停车后安装、设置和排查。用支持数据传输的数据线连接车机 USB-A；目标车机 USB-C
仅用于充电。异常时退出应用并恢复原车功能，诊断报告分享前先检查个人信息。

这是独立社区实验项目，不是领克、DiPlay 或 Apple 官方产品。完整 APK 包含可提取的
实验认证素材，不是为本项目签发的新 MFi 身份；未来 iOS 接受性与持续可用性无法保证。
代码许可证不授予第三方素材权利。原作者、贡献者署名和许可证说明保留。

构建入口和签名连续性见 [BUILD.md](BUILD.md)，历史自动/模拟器/实车证据见
